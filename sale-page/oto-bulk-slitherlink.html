Bundles

Games in a set sell for more than games alone.

Pick 3–12 games from your saved projects, or create new ones. Slide to see what each extra game adds.

  • Three kinds of bundle. Seasonal or themed sets, a difficulty ladder (Easy to Hard), or a whole-year set — 12 games, one for each holiday.
  • Everything assembled. A bundle cover and contents page, a “How to use this bundle” page, then every game in full. KDP editions become a single book, with the host pages (answers, questions, hint cards) gathered at the back.
  • A Master Code. Each game gives one more secret letter when it’s solved; together they spell a master code for the whole bundle, with a special certificate.
  • No clashes. No repeated codes or puzzles inside a bundle, and one paper size and style throughout.

Bulk story prompts

Ten new stories, without ten copy-paste jobs.

Only needed when each game has a different story. Say you want N new games and the Builder writes prompts for exactly N stories, split into small batches that AI tools handle reliably.

Batch 2 / 4Paste the reply
  • Small batches. Prompts cover 2–3 games at a time, because long replies are where AI tools drift or get cut off.
  • Labelled blocks, not JSON. Replies use === GAME 1 ===, TITLE:, CHAPTER 1: and so on, and the reader forgives small slips.
  • Checked game by game. Each story is validated alone, then checked against the others — no clashing codes or titles, one voice, secret letters that fit the Master Code.
  • Partial replies are fine. Accept the games that passed and re-run only the rest. If a reply is cut off, the Builder writes a “continue from game 6” prompt for you.
  • One screen. A Copy prompt button, one paste box, a batch counter and a status for every game: Waiting, Valid, Error or Fixed by hand.

Games you pick from your saved projects need no prompt. Variants of one story share a single story, so they need none either.

Straight answers

Before you decide.

Do I need any other upgrade first?
No. Bulk Creator runs on your Builder alone. If you also own other game types, Bulk Creator works on those too — nothing about it depends on what else you have.
Are variants the same puzzles in a different size?
No. Each variant is generated as its own puzzle set with its own answer key. The story, code and 20 hint questions are shared; the puzzles are not, which is why every footer carries a variant code.
How long does a big batch take?
Everything runs in your browser with a progress bar, so it depends on your computer and on how many PDFs you ask for. A large batch will naturally take longer than a single game.
Do bundles need AI prompts?
Only if you want new stories. Bundles built from your saved games need no prompt, and variants share one story. When you do need fresh stories, the bulk prompt writes them in small, checkable batches.
Will bundles fit Etsy and KDP?
The Builder checks file sizes against marketplace limits and lets you choose one merged PDF or one file per game. For KDP it keeps one trim size throughout and a minimum page count.
