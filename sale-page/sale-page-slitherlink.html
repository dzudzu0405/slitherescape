Why these never get listed

Puzzles are easy to find. A sellable escape game is not.

A real escape game is thirty-odd pages that all have to agree with each other: the story, the code, the puzzles, the hints, the host guide. That is where most listings stall.

Making one by hand

  • Source or draw puzzles, then check each has exactly one solution
  • Design letter shapes that still work when drawn as a single loop
  • Write a story whose secret code matches the number of puzzles
  • Build hint cards, a host guide and an answer key that all line up
  • Rework every page for A4, Letter and KDP trim sizes
  • Start again for the next game — and risk duplicate content

Group play

Everyone works the same game. The host shares the puzzles out between players, who fill in one shared Code Sheet. Works for 2–6 players.

Team play

Each team gets its own copy. The first team to open the Final Lock wins, and each hint adds an optional two-minute penalty. Same pages, different hand-out.

Hints you have to earn

Stuck? Answer a question first.

Players don’t just flip to the answer page. A hint is a prize for reading the story and paying attention.

Ask the Host

The host reads out a multiple-choice question from the game’s set of 20 — part story, part theme trivia. Answers are shuffled between A, B and C.

Answer right, get a card

A correct answer earns the next hint card for the puzzle they choose. Hint 1 must come before Hint 2.

Answer wrong, wait

A wrong answer means a two-minute wait before trying a different question. Nobody can brute-force the hints.

Straight answers

Before you decide.

Do I need an AI subscription?
The Builder never calls an AI service itself. It writes the story prompt for you; you paste it into whichever AI chat you already use, then paste the reply back and the Builder checks it. If you would rather not use AI, ready-made story templates are included.
Can I really sell the games?
Yes. The PDFs you export are yours to sell on Etsy, Amazon KDP and other marketplaces, and the fonts, textures and ornaments in them are licensed for commercial use. What is not included is reselling the Builder itself. You are also responsible for the story text the AI writes for you — the prompt tells the AI to write original content and avoid copyrighted characters and names, but it is worth a read before you list.
Who actually plays these?
Students aged 11–17 and adults, in a hosted game for 2–6 players — one person runs the hints and the Final Lock. Games are for printing, not for playing on screen.
What if my players have never done Slitherlink?
Every game prints a How to Play page with the full rules and a small worked example, shown unsolved and solved. Easy uses only the basic rules.
How do I know a puzzle really has one answer?
Each puzzle is checked by a second solver that counts solutions, and the export is blocked unless every puzzle in the game passes. A puzzle with more than one solution is discarded and a new one is generated.
Which paper sizes can I export?
A4 and US Letter for Etsy-style downloads, and KDP 8.5×11 with bleed and a gutter margin. The certificate is always landscape.
Do I need to install anything?
No. It is a web app: puzzles are generated and the PDF is built in your browser, so you only need a modern browser and a printer or a KDP account to use the result.
