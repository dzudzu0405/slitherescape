You are writing the story for a printable escape-room game for teenagers aged 14-17.
How the game works: players solve logic puzzles, and each solved puzzle reveals ONE capital letter. Read in order, the letters spell a SECRET CODE of 3 words, one word per chapter. Saying the code at the end opens the final lock and wins the game.

== BRIEF ==
Theme: A summer wedding by the sea
Story type: Mystery. Something has been stolen, sabotaged or has gone missing; the players gather clues and the final code names the solution or the culprit.
Audience: teenagers aged 14-17. Lively and a little witty, with light suspense. No graphic violence, no romance beyond friendship.
Language: English, with American spelling (color, harbor, favorite).

== THE SECRET CODE ==
- Choose 3 common English words, exactly 12 letters in total, using only the letters A-Z.
- Suggested split: 4 + 4 + 4 letters (any split works if the total is 12).
- Pick words teenagers aged 14-17 know and can spell. No names, no abbreviations, no made-up words.
- Read together, the words form one meaningful phrase (for example adjective + noun, or a short command). Never a list of unrelated words.
- That phrase is the answer to the story's problem, in a way that fits the story type.

== WHAT TO WRITE ==
1. title (max 8 words): catchy and original.
2. tagline (max 15 words): one intriguing line for the cover.
3. prologue (90-150 words): sets up the problem and why the code matters. Plant at least 6 concrete details players can be asked about later: names, colors, numbers, objects, places, times.
4. mission (20-50 words): tells the players to solve the puzzles, collect the 3 words and say the code before something bad happens.
5. chapters: exactly 3, in the order of the code. For each:
   - name (max 6 words)
   - intro (50-110 words): narration that leads into this chapter's puzzles and raises the stakes, with at least 3 new concrete details.
   - riddle (max 35 words): printed on the players' Code Sheet; its answer is exactly this chapter's word. Fair and solvable for teenagers aged 14-17. It must not contain the word or any form of it.
   - word: this chapter's code word in CAPITALS.
6. puzzleTitles (exactly 12 items): one short scene title per letter, max 7 words each, built from places and objects in that chapter's intro. The titles follow the letters in order: the first titles are scenes from chapter 1, then chapter 2, and so on.
7. finalLock (35-90 words): the tense moment just before the players speak the code.
8. ending (70-150 words): read aloud by the Game Host once the code is cracked; explains why the code was the answer, resolves the story and congratulates the players.
9. certificate (max 25 words): one sentence of praise printed on the certificate of completion.
10. teamName (max 6 words): a fun name for the players' team.
11. questions: exactly 20 multiple-choice questions. The Game Host reads one aloud whenever players want a hint.
   - Questions 1-12, kind "story": the answer is stated in the prologue, the mission or a chapter intro. Never ask about the final lock or the ending. Each question asks about a different detail.
   - Questions 13-20, kind "trivia": about the theme. Well-known facts that teenagers aged 14-17 can answer or reasonably guess; nothing disputed or likely to change.
   - Exactly 3 options each, exactly 1 correct. Wrong options are plausible, never jokes. Options max 8 words, questions max 28 words. No "all of the above" or "none of the above".
   - "answer" is the position of the correct option: 0, 1 or 2.

== STAY IN THE STORY ==
- Only the mission may mention puzzles. The prologue, chapter intros, final lock and ending stay inside the story world: never mention puzzles, riddles, letters, word lengths, how many puzzles there are, or how the game works.
- Details stay consistent: every name, number, color and time means the same thing everywhere, and any times mentioned add up. Puzzle titles and the ending must not contradict the intros.

== NO SPOILERS ==
- Never use a code word (or its plural) in the riddles, puzzle titles, final lock or questions: that would give the answer away.
- Never hint at what a code word means or how long it is in the story text.
- Avoid the code words in the title, tagline, prologue, mission and chapter intros too. Only if a code word is the theme's own name may it appear there naturally, never highlighted as a clue.
- The ending may use the code freely.

== ORIGINALITY ==
100% original writing. No copyrighted or trademarked characters, brands, places or names (for example Harry Potter, Disney, Marvel, Pokemon).
